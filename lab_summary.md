# Lab Summary

In this lab, I built a Multi-Provider News Summarizer that combines NewsAPI, OpenAI, and Cohere into one automated workflow. One of the main challenges was understanding how different LLM providers return responses and token usage data in different formats. I addressed this by creating separate provider functions with a consistent output structure and implementing direct API usage tracking with a shared TokenBudgetManager. I also added retry and fallback functionality to make the integration more reliable. During development, I encountered some syntax and dependency issues, which I resolved through debugging and testing individual components step by step. I learned how to structure a Python project into reusable modules, connect multiple APIs, track estimated costs, and use mocked responses for unit testing without generating additional API costs. All four unit tests passed, and the complete workflow ran successfully. For future improvements, I would focus on better news filtering, persistent budget tracking, and asynchronous processing to improve performance when handling larger numbers of articles.
